\begin{abstractutfpr}%% Ambiente abstractutfpr
    With the end of Moore's Law and Dennard scaling, different computational techniques have emerged to meet the demand for higher computational performance and energy efficiency. Approximate Computing increases the performance and energy efficiency of applications in exchange for a loss of accuracy in the results. Parallel Computing achieves higher performance through better utilization of \textit{multicore} processors. \texttt{OpenMP} is a tool that facilitates the development of parallel applications through code annotations. The objective of this work is to improve the performance and energy efficiency of applications through the implementation of approximation techniques in \texttt{OpenMP}. The implementations modify the \textit{runtime} infrastructure and the code translation process of \texttt{OpenMP} within the \texttt{LLVM} infrastructure. The implemented techniques are: loop perforation, approximate memoization, and floating-point relaxation. The proposed techniques were evaluated on a set of seven approximation-tolerant applications, allowing for an analysis of the impact of these approximations on performance and accuracy. It is expected that the obtained results will demonstrate the potential of combining approximation and parallelization to improve application performance.
\end{abstractutfpr}

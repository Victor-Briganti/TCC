With the end of Moore’s Law and Dennard scaling, different computational techniques have emerged to meet the demand for higher computational performance and energy efficiency. Approximate Computing improves performance and energy efficiency at the cost of reduced precision in application results. Parallel Computing achieves higher performance through better utilization of multicore processors. \texttt{OpenMP} is a tool that facilitates the development of parallel applications through code annotations. The objective of this work is to improve the performance and energy efficiency of applications by implementing approximation techniques in \texttt{OpenMP}. These implementations modify both the \textit{runtime} infrastructure and the code translation process of \texttt{OpenMP} within the \texttt{LLVM} infrastructure. The implemented techniques include loop perforation, approximate memoization, and floating-point relaxation. The proposed approaches were evaluated using a set of seven approximation-tolerant applications, allowing the analysis of the impact of these approximations on performance and accuracy. The obtained results are expected to demonstrate the potential of combining approximation and parallelization to improve application performance.
\end{abstractutfpr}
